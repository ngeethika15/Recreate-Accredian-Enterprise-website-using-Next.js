# Accredian Enterprise Page Clone

A responsive partial clone of the Accredian Enterprise landing page built with Next.js 14 (App Router), Tailwind CSS, and TypeScript, featuring modular UI components and an integrated lead capture API system.

- **Live Demo:** [Accredian Enterprise Live App](https://recreate-accredian-enterprise-website-using-next-ccppo0gxz.vercel.app/)
- **GitHub Repository:** [Recreate-Accredian-Enterprise-website-using-Next.js](https://github.com/ngeethika15/Recreate-Accredian-Enterprise-website-using-Next.js)

---

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Language:** TypeScript
- **Backend/API:** Next.js Route Handlers
- **Deployment:** Vercel
